# Fisiología renal · Renal physiology

**ES** · [EN](#english)

## Español

Diagrama de flujo para estudiantes de medicina: entrada vascular, los cuatro procesos de la nefrona (filtración, reabsorción, secreción y excreción), el recorrido segmento por segmento con sus transportadores y su regulación hormonal, y la formación de orina.

Es la base para correlacionar después con patología (lesión renal aguda y tubulopatías). Cada segmento lleva un identificador (`data-segmento`) para añadir esas capas.

**Ver en línea:** https://viijx-stack.github.io/fisiologia-renal/ (después de activar GitHub Pages). La página tiene selector ES/EN; la versión en inglés está en `#en`.

## English

A flow diagram for medical students: vascular input, the four nephron processes (filtration, reabsorption, secretion and excretion), a segment-by-segment walk through the nephron with its transporters and hormonal regulation, and urine formation.

It is the base for correlating later with disease (acute kidney injury and tubulopathies). Each segment carries an identifier (`data-segmento`) for adding those layers.
